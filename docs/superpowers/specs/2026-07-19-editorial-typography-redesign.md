# 凯迪欧网站 - 编辑式排版重设计

## 目标

将现有“暗色工业展示站”从超大压缩标题、细小等宽标签和等密度卡片中解放出来，建立适合工程甲方、经销商与海外采购商阅读的建筑材料品牌排版系统。首要指标是：中文自然、信息可信、真实案例图片成为视觉主角。

## 设计方向

### 视觉立场

采用“材料画册，而非科技发布会”的方向。石墨黑、矿物白和地坪绿仍保留，但绿色只承担定位与行动提示，不作为大面积装饰。网站的记忆点是来自地坪标线的细绿色“接缝线”：它只在段落引导、活动状态和主要行动上出现。

### 字体与层级

- 中文显示字体使用 `DengXian` / `PingFang SC` / `Microsoft YaHei UI` 的系统优先级，避免 Bahnschrift 的压缩感主导中文。
- 正文使用清晰的系统无衬线，最小阅读字号不低于 16px，正文行高 1.7 左右。
- 英文、尺寸与产品代码使用克制的实用无衬线，而不是在中文标签中强行使用等宽字体。
- 主标题在桌面端限定在约 4.9rem，手机端约 3rem，并使用平衡断行；不使用人为的 `<br>` 海报断句。
- H2、H3 和元数据拉开明显差距，卡片正文不再与标题竞争。

### 布局

- 首屏保留真实车库图，标题占更少横向面积，图片有足够留白；文字不再压到图片上形成海报式拥挤。
- 首页案例区采用一个宽主案例加两张辅助案例，文字在图片下以标题、系统、面积、来源四级阅读。
- 产品与受众卡片去除“每一块都一样大”的压力，以更大的内边距、更少边框、更稳定的文字宽度形成节奏。
- 电脑端保持 12 列网格；平板和手机端优先单列阅读，确保标题最多自然分为 2-3 个主要视觉段落，不出现横向滚动。

### 交互与可访问性

- 保留已有键盘焦点、跳转链接和图片替代文本。
- hover 只使用轻微的图片和边框变化；尊重 `prefers-reduced-motion`。
- CTA 保持单行、44px 以上点击面积和足够对比度。

## 不做的事

- 不增加玻璃拟态、霓虹网格、伪数据仪表盘、客户 Logo 墙、装饰性编号或连续的 AI 动效。
- 不把客户名称写成背书；案例仍保留“官网公开案例”的来源边界。
- 不引入运行时字体包，避免为视觉效果牺牲国内访问速度与首屏稳定性。

## 验收

1. 首页桌面与 390px 手机截图中，标题、正文和案例卡存在清晰三级以上的字体层级。
2. 中文主标题不使用压缩式英文字体的视觉效果，不出现破碎的逐字换行。
3. 全量单元测试、构建和桌面/平板/手机 Playwright 回归通过；无横向溢出和控制台错误。
4. GitHub Pages 发布后，主页、产品详情和询盘路径可正常访问。
